Base container for every dashboard block (charts, tables, lists).
```jsx
<Card title="Preço médio por marca" subtitle="Últimos 30 dias" actions={<IconButton icon="dots-three" variant="ghost" size="sm" label="Mais" />}>…</Card>
<Card variant="accent">Destaque</Card>
```
- Use `accent` for the single most important highlight on a page.
