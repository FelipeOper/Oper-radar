Pill button for any action; `primary` (radar green) is the single main action per view.
```jsx
<Button icon="export">Exportar CSV</Button>
<Button variant="secondary" size="sm">Cancelar</Button>
<Button size="lg" endCircle>Iniciar coleta</Button>
```
- variants: primary · secondary · outline · ghost · inverse (white pill on dark) · danger
- sizes: sm 32 · md 40 · lg 48 — all radius pill
- `endCircle` puts the trailing arrow in a black disc (hero CTA, from the reference "Book a ride" pattern)
